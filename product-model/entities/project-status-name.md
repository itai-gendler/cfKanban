# Project status name

One Project display name for a fixed workflow key; its category, order and terminal property remain fixed.

## Information kept

- **Project** — The project of this project status name, retained or disclosed with the object.
- **Status key** — The status key of this project status name, retained or disclosed with the object.
- **Display name** — The display name of this project status name, retained or disclosed with the object.
- **Category** — The category of this project status name, retained or disclosed with the object.
- **Position** — The position of this project status name, retained or disclosed with the object.
- **Terminal** — The terminal of this project status name, retained or disclosed with the object.
- **Project version** — The project version of this project status name, retained or disclosed with the object.

## States

### Default

Default name of the fixed workflow state.

### Renamed

Current Project-specific display name of the fixed state.
